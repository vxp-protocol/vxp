# VXP specification

The normative text of VXP draft 0.1 is [`../site/spec/index.html`](../site/spec/index.html),
published at https://vxpprotocol.org/spec/. It includes the normative annex for VXP Proof (§9),
the native profile (experimental) and the adapters for Poppy draft 0.2 and PACT 1.0.

What the verifiers check, control by control, is described in [`../verifier/CHECKS.md`](../verifier/CHECKS.md).
The conformance vectors are in [`../vectors/`](../vectors/).
