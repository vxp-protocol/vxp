Read this first

This is a self-run conformance record by SOVRAS, and it is not an independent certification. The Poppy and PACT suites are official and unmodified, but SOVRAS ran them on its own machines against its own implementation. Nobody outside SOVRAS has reproduced these results yet.

Three classes, never added together. Official tools of other protocols are published by the Poppy and PACT projects and run unchanged. Own adapter tests are written by SOVRAS to check its adapters where no official tool reaches. VXP tests check VXP itself. A pass in one class says nothing about the others.

The official PACT delegated suite only runs against PACT's demo airline. To test delegated authority against VXP, SOVRAS wrote its own delegated test with the official PACT client. It is an own adapter test, not the official suite.

Environments. In process: the test starts the server inside its own Node.js process. Local server: a separate server process on the same machine, reached over TCP. Offline: the verifier reads files, with no server. Public tunnel: a local server reached from the internet through a tunnel.

Class 1

Official tools of other protocols

Written and published by the Poppy and PACT projects, and run unchanged. They check that VXP's adapters keep those protocols' own contracts. They do not check VXP Proof, VXP Relationship or the operation requirements. The Poppy validator's result is not full Poppy conformance: this version of the kit covers discovery and conversations, and does not check sign-in or Operations.

What the tests caught

Failures found in the reference implementation, and fixed

  1. A VXP field leaked into the PACT Agent Card

    The vxp:relationship checkbox was published as a scope in the PACT Agent Card. The delegated test with the official PACT client detected it.

  2. The verifier compared with the first outcome

    It compared the operation's state with the first outcome, instead of the last final statement.

  3. Three mutations went undetected

    Until their tests were added: a write in a traditional channel, a phone number shared by two customers in a channel, and a relationship that survived revoking the delegation.

  4. Expanding permissions over Poppy added the earlier scopes (22 Oct)

    Poppy draft 0.2 §4.4: «The Company MUST NOT grant scopes beyond those requested». The token now carries only what was requested; test H3 and the mutation permisos_suman cover it.
