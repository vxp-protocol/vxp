    Failures and how VXP behaves

    What a company, an agent and a verifier do when authority is missing, a permission is revoked, terms change, a request repeats or a result is unknown. Every row is covered by a test in the repository.

    On this page

    • Missing or wrong authority
    • Revocation and expiry
    • Changed or altered terms
    • Duplicates and lost answers
    • Results nobody can confirm yet
    • Inside a relationship

    Each row names the test that covers it. Tests in reference/ run with npm test (and npm run test:network for test-red/); tests in agent/ with npm test in that folder; the conformance validator runs the same checks against any implementation (Conformance). Error codes are those of the specification.
