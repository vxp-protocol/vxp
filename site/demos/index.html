    Adding a demo

    A demo lives apart from the protocol's own code, so it can change, or be removed, without touching the specification, the verifier or the captured data.

    1. Its own folder. Everything goes in site/demos/<name>/, with its own index.html and its own assets. The name uses lowercase letters, digits and hyphens.
    2. No shared code. A demo does not import from assets/, verify/, spec/, docs/ or downloads/. If it needs a file from there, it keeps its own copy.
    3. Honest data. It uses the neutral test companies. Captured data names its source on screen; anything invented is labeled as illustrative.
    4. Registered in one place. One entry in site/demos/demos.json makes it appear on this page. With "embed": "page" it gets a link to its own page; with "embed": "iframe" it can also be loaded here, in a sandboxed frame, only when the visitor asks.
    5. Same bar as the site. Usable at 390 px wide without horizontal scroll, reachable by keyboard, with visible focus, and with no motion under prefers-reduced-motion.
