A · Observed operations · evidence

What the agents did on 21 October 2026, and what stayed in the system

Eight operations with an effect on a store and a hotel, and one request the hotel started within a relationship. Every field comes from the server's evidence. Times are UTC, with Chile time (UTC−3) in parentheses.

  • Production, and simulated parts. The operations ran in SOVRAS's production with customers, first on SOVRAS's own resources. In the evidence, the two companies are configured as test environments, and payments and the WhatsApp line are simulated.
  • The simulated WhatsApp line is the company's approval channel. The one-time code it sends was read by the operator. It is not a personal agent.
  • The agents. Personal agents came in through the Poppy adapter, among them Nova, the personal agent SOVRAS uses internally, which works on the person's side: the person talks to it on WhatsApp, and Nova goes to the company through Poppy. The evidence keeps those sessions as temporary identities and does not separate which agent ran each operation. Grok, a third-party web agent, came in through the web pages in OP-3, OP-5, OP-6 and OP-8; in OP-6 and OP-8 the attribution comes only from the user agent, with no signature.
  • No agent used PACT or the native profile. The access log of the hotel session has no /a2a or /v1 request from an agent.
  • What this family does not claim. No external corroboration, no financial effect beyond what the records show, and no autonomy of any agent beyond what each record shows.
  • Customers appear as Customer A and Customer B; phone numbers, addresses, IP addresses, codes and the agents' tunnel hosts are left out.

C · Conceptual scenes · not evidence

Illustrations of the protocol

Objects written to teach the format, and scenes the protocol allows that have not run. Nothing here happened to a customer, and none of it is evidence.

Objects that teach the format

The first comes from the specification. The others come from the test vectors: a chain signed with test keys for an order whose delivery moves from 24 to 28 October.

JSON reformatted for reading; values unchanged. The vector file carries test-only keys derived from public phrases.

Scenes that have not run

Each is pending in the specification (Status). None has run with a third party.

Not executednative profile

A third-party agent on the native profile

An agent that speaks neither Poppy nor PACT discovers vxp.json, receives per-request authority, operates and gets the proof. Today only SOVRAS's test agents have run this cycle.

Not executedVXP Relationship over HTTP

A company proposal to the agent's own inbox

The company signs a proposal and delivers it to an inbox_uri the agent publishes; the person approves and the agent accepts. Today tested only with SOVRAS's own inbox.

Not executedPACT adapter

A PACT agent from outside SOVRAS

A third-party PACT agent delegates by device code, operates, and receives both its PACT receipt and the VXP proof bound to it.

Not executedrelationship over PACT

A relationship carried over A2A

The company-initiated request travelling over PACT. Its specification and tests are still to be written.

Not executedVXP Proof

A proof that does not rest on the operator alone

An operation whose proof is anchored in a public log with external witnesses, with the company's key held outside the operator and a second independent issuer, so the verifier can derive more than an operator attestation.
