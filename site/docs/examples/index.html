    More examples#

    • Failures, on purpose: the conformance validator's run against the reference shows each refusal it checks: a missing Idempotency-Key, a reused key, terms_changed, a tampered outcome, an answer outside the options, a second answer, and a request after revocation (node conformance/reference/run.ts).
    • Tampered proofs: the Verify page alters a published proof in five ways and shows each rejection.
    • Test vectors: vectors/vectores-0.1.json holds valid chains and negative cases, each with the verdict and error a conforming verifier must return.
    • Operations with live agents (21 October 2026) are described on the Examples page, with what can and cannot be verified about each.
